Valkey.app

The easiest way to run Valkey on your Mac.

Download for macOS

macOS 13 or later · Apple Silicon and Intel · install steps · release notes

Install

  1. Download Valkey.dmg, open it, and drag Valkey.app into Applications.
  2. Open Valkey.app from Applications. macOS blocks the first launch because Valkey.app isn't notarized by Apple yet. Allow it once, as shown below.
  3. Click Create Server…, pick a Valkey version, and it's downloaded and set up. From then on Valkey.app updates itself.
Allow Valkey.app on macOS 15 Sequoia and later
  1. Open Valkey.app once. When macOS says it can't be verified, click Done.
  2. Open System Settings → Privacy & Security and scroll to Security.
  3. Next to “Valkey.app was blocked to protect your Mac”, click Open Anyway, then confirm with your password or Touch ID.
Allow Valkey.app on macOS 13 Ventura or 14 Sonoma
  1. In Applications, Control-click (or right-click) Valkey.app and choose Open.
  2. Click Open in the dialog.
Prefer the Terminal?

This removes the download quarantine flag, so macOS won't block the first launch:

xattr -dr com.apple.quarantine /Applications/Valkey.app

You only need to do this once. Updates and Valkey versions installed by the app aren't blocked, and every download is checked against its published signature and checksum.

Features

  • Multiple serversRun several servers side by side, each on its own port and data directory.
  • Any Valkey versionInstall versions from a signed registry — new releases arrive without an app update.
  • Live logsEvery server has its own log, right in the window.
  • Menu barStart, stop and connect with valkey-cli from the menu bar.
  • ModulesAdd official modules like JSON and Bloom to any server, matched to its Valkey version.
