Valkey for macOS

Valkey.app is the easiest way to run Valkey for macOS.

Download for macOS

Free · macOS 13 or later · Apple Silicon and Intel · release notes

First launch: allow it once in Privacy & Security. It takes 30 seconds. Why?

Valkey.app is Valkey for macOS: a free, native macOS app for running Valkey, the open-source Redis alternative, on your Mac. Like Postgres.app does for PostgreSQL, it runs local Valkey servers without Homebrew, Docker or a terminal: each server has its own port, Valkey version, data directory and live log. Comparing options? See how to install Valkey on Mac with Valkey.app, Homebrew, Docker or from source.

Install

  1. Download Valkey.dmg, open it, and drag Valkey.app into Applications.
  2. Open Valkey.app from Applications. The first time, macOS asks you to confirm it, because the app isn't notarized by Apple yet (why). Allow it once, as shown below.
  3. Click Create Server…, pick a Valkey version, and it's downloaded and set up. From then on Valkey.app updates itself.

Install with Homebrew

Prefer brew? Install the app as a cask, then allow it once with the last command:

brew install --cask alhassanaraouf/tap/valkey
xattr -dr com.apple.quarantine /Applications/Valkey.app

This installs Valkey.app itself, not the valkey server formula. Update with brew upgrade --cask valkey, or let the app update itself.

Allow Valkey.app on macOS 15 Sequoia and later
  1. Open Valkey.app once. macOS says it can't verify the app; click Done.
  2. Open System Settings → Privacy & Security and scroll to Security.
  3. Next to “Valkey.app was blocked to protect your Mac”, click Open Anyway, then confirm with your password or Touch ID.
Allow Valkey.app on macOS 13 Ventura or 14 Sonoma
  1. In Applications, Control-click (or right-click) Valkey.app and choose Open.
  2. Click Open in the dialog.
Prefer the Terminal?

This removes the download quarantine flag, so macOS won't block the first launch:

xattr -dr com.apple.quarantine /Applications/Valkey.app

You only do this once. Updates and the Valkey versions the app installs don't ask again, and every download is checked against its published signature and checksum.

Why isn't it notarized?

Valkey.app is a free, open-source side project. Apple only notarizes apps from members of its paid Developer Program, and joining is planned. Until then, macOS asks you to allow the app once. You don't have to take that on trust: everything below can be checked.

Verify it yourself

  • Open source. All of the code is on GitHub under the Apache License 2.0.
  • Built in the open. Release DMGs are built by GitHub Actions from the tagged commit, by this workflow, not on a personal machine.
  • Checksums. Every release's notes list the SHA-256 of Valkey.dmg and Valkey.app.zip. Compare with: 
    shasum -a 256 ~/Downloads/Valkey.dmg
  • Build provenance. From the release after 1.5 on, GitHub signs an attestation that the DMG came from that workflow. Check it with the GitHub CLI: 
    gh attestation verify Valkey.dmg -R alhassanaraouf/Valkey.app
  • Malware scan. Paste the DMG's SHA-256 into VirusTotal to see its scan. Newer release notes link the report directly.
  • Code signature. From the release after 1.5 on, the app is signed with the same self-signed identity every time, so macOS keeps its Keychain access across updates. It's not a substitute for notarization, but you can see it with codesign -dv /Applications/Valkey.app.
  • Signed downloads. App updates are Ed25519-signed and checked before they install. Valkey and module downloads are checked against the SHA-256s in the Ed25519-signed registry.json.

Frequently asked questions

What is Valkey.app?

Valkey.app is a free, open-source macOS app for running Valkey servers on your Mac, in the spirit of Postgres.app. Each server gets its own port, Valkey version, data directory and live log, and you can start, stop and connect to them from the window or the menu bar.

What is Valkey?

Valkey is an open-source (BSD-licensed), high-performance key-value datastore maintained under the Linux Foundation. It was forked from Redis 7.2.4 and speaks the Redis protocol, so existing Redis clients, libraries and tools work with it.

Which Macs does Valkey.app run on?

Any Mac with macOS 13 Ventura or later, on Apple Silicon or Intel. The app and every Valkey build it installs are universal binaries.

Can I install Valkey.app with Homebrew?

Yes. Install the app as a cask with brew install --cask alhassanaraouf/tap/valkey, then allow it once (the app isn't notarized yet). This installs Valkey.app itself, not the valkey server formula. See how to install Valkey on Mac.
