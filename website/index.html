Valkey for Mac

Valkey.app is the easiest way to run Valkey on macOS.

Download for macOS

Free · macOS 13 or later · Apple Silicon and Intel · install steps · release notes

Valkey.app is a free, native macOS app for running Valkey, the open-source Redis alternative, on your Mac. Like Postgres.app does for PostgreSQL, it runs local Valkey servers without Homebrew, Docker or a terminal: each server has its own port, Valkey version, data directory and live log. Comparing options? See how to install Valkey on Mac with Valkey.app, Homebrew, Docker or from source.

Install

  1. Download Valkey.dmg, open it, and drag Valkey.app into Applications.
  2. Open Valkey.app from Applications. macOS blocks the first launch because Valkey.app isn't notarized by Apple yet. Allow it once, as shown below.
  3. Click Create Server…, pick a Valkey version, and it's downloaded and set up. From then on Valkey.app updates itself.
Allow Valkey.app on macOS 15 Sequoia and later
  1. Open Valkey.app once. When macOS says it can't be verified, click Done.
  2. Open System Settings → Privacy & Security and scroll to Security.
  3. Next to “Valkey.app was blocked to protect your Mac”, click Open Anyway, then confirm with your password or Touch ID.
Allow Valkey.app on macOS 13 Ventura or 14 Sonoma
  1. In Applications, Control-click (or right-click) Valkey.app and choose Open.
  2. Click Open in the dialog.
Prefer the Terminal?

This removes the download quarantine flag, so macOS won't block the first launch:

xattr -dr com.apple.quarantine /Applications/Valkey.app

You only need to do this once. Updates and Valkey versions installed by the app aren't blocked, and every download is checked against its published signature and checksum.

Features

  • Multiple serversRun several servers side by side, each on its own port and data directory.
  • Any Valkey versionInstall versions from a signed registry — new releases arrive without an app update.
  • ModulesAdd official modules like JSON and Bloom to any server, matched to its Valkey version.
  • Live logsEvery server has its own log, right in the window.
  • Menu barStart, stop and connect with valkey-cli from the menu bar.
  • Automatic updatesSee the release notes and confirm before anything is installed.

Frequently asked questions

What is Valkey.app?

Valkey.app is a free, open-source macOS app for running Valkey servers on your Mac, in the spirit of Postgres.app. Each server gets its own port, Valkey version, data directory and live log, and you can start, stop and connect to them from the window or the menu bar.

What is Valkey?

Valkey is an open-source (BSD-licensed), high-performance key-value datastore maintained under the Linux Foundation. It was forked from Redis 7.2.4 and speaks the Redis protocol, so existing Redis clients, libraries and tools work with it.

Is Valkey.app free?

Yes. Valkey.app is free and open source under the Apache License 2.0. Valkey itself is BSD-licensed.

Which Macs does Valkey.app run on?

Any Mac with macOS 13 Ventura or later, on Apple Silicon or Intel. The app and every Valkey build it installs are universal binaries.

Why does macOS say Valkey.app can't be verified?

Valkey.app isn't notarized by Apple yet, so macOS blocks its first launch. Allow it once: on macOS 15 and later, open System Settings, go to Privacy & Security and click Open Anyway; on macOS 13 and 14, Control-click the app and choose Open.
