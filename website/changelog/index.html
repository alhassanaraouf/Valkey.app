Valkey.app changelog

Every release of Valkey.app, newest first. Valkey.app 1.2 and later update themselves: the app shows the release notes and asks before installing anything.

1.4.2 · 2 Oct 2026

  • Passwords and users. Server Settings has a password for the default user and a Users list for extra accounts with full or read-only access. Passwords live in your Keychain and are handed to the server privately, never on its command line.
  • Copy URL. Copies valkey://127.0.0.1:PORT (with the password when set) from the server window or the menu bar.
  • Max memory and eviction policy per server.

Full notes for 1.4.2 on GitHub

1.4.1 · 2 Oct 2026

  • Send Feedback… and Report a Bug… in the Help and menu-bar menus. Each opens a draft email to review before sending; bug reports include app, macOS and Valkey versions plus recent log lines.
  • One-click error reporting from error messages.
  • Fix: a damaged saved server list no longer wipes your servers.

1.4 · 26 Sep 2026

  • Modules. Add official Valkey modules to any server: JSON (documents with JSONPath queries) and Bloom (Bloom filters). Each build is tested against the Valkey versions it's offered for.
