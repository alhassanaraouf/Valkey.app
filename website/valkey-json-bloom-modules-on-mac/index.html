How to use the Valkey JSON and Bloom modules on Mac

Valkey has official modules for JSON documents and Bloom filters. On Linux you'd load them from a package or a container. On a Mac, Valkey.app downloads a build that matches your server's Valkey version and turns it on per server.

What the modules do

  • JSON: native JSON documents with JSONPath queries (JSON.SET, JSON.GET, …). Read or update one field without fetching the whole document.
  • Bloom: scalable Bloom filters for fast membership checks (BF.ADD, BF.EXISTS, …). "Have I seen this before?" in a small, fixed amount of memory, with a small chance of false positives and none of false negatives.

Each module build is tested against the Valkey versions it's listed for. Right now JSON and Bloom both work with Valkey 8.0 through 9.2; neither is offered for 7.2. The modules table on the home page is always current, or ask the app:

valkey-app modules --valkey 9.1.4

Turn a module on in the app

  1. Select a server and open Server Settings….
  2. Under Modules, click Add Module… and pick JSON or Bloom. Only modules that work with the server's Valkey version are offered.
  3. Click Save. The module is downloaded, checksum-verified, and the server restarts with it if it was running.

To turn a module off, remove it from the list with −. Data saved while a module was on may need it to load, so keep it on for servers that store JSON or Bloom keys.

Or from Terminal

With the valkey-app command (Settings › Command Line › Install CLI, or linked by the Homebrew cask), create a server with JSON on from the start:

valkey-app create docs --enable-module json
valkey-app start docs

Or add Bloom to a server you already have:

valkey-app set docs --enable-module bloom

valkey-app show docs lists each module with its status (installed, will download, or not available for that version). --disable-module turns one off, and --modules json,bloom sets the whole list at once.

Try JSON

valkey-app cli runs the server's own valkey-cli, already connected:

valkey-app cli docs JSON.SET user:1 '$' '{"name":"Ada","langs":["swift","c"]}'
# OK
valkey-app cli docs JSON.GET user:1 '$.name'
# "[\"Ada\"]"
valkey-app cli docs JSON.ARRAPPEND user:1 '$.langs' '"rust"'
valkey-app cli docs JSON.GET user:1 '$.langs'
# "[[\"swift\",\"c\",\"rust\"]]"

Paths starting with $ are JSONPath, so results come back as a JSON array of matches.

Try Bloom

valkey-app cli docs BF.ADD seen:emails ada@example.com
# (integer) 1
valkey-app cli docs BF.EXISTS seen:emails ada@example.com
# (integer) 1
valkey-app cli docs BF.EXISTS seen:emails bob@example.com
# (integer) 0

The filter is created with default settings on the first BF.ADD. Use BF.RESERVE first if you want to set the error rate and capacity yourself.

The alternative: valkey-bundle in Docker

The Valkey project publishes a valkey/valkey-bundle image with the official modules already loaded:

docker run -d --name valkey-bundle -p 6379:6379 valkey/valkey-bundle

That works well if you already use Docker. Every server from the image gets every module in it, and Valkey runs in a Linux VM. Homebrew's valkey formula doesn't include the modules, so you'd build them yourself.
