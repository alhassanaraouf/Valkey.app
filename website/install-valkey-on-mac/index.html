How to install Valkey on Mac

There are four ways to run Valkey, the open-source Redis alternative, on macOS: a native app, Homebrew, Docker, or building from source. All of them work on Apple Silicon and Intel Macs. Here's how each one works and which to pick.

For local development, Valkey.app is the quickest start and the easiest way to run different Valkey versions. Homebrew suits people who already manage their tools with brew. Docker is a good fit if your project already runs in containers.

1. Valkey.app (native macOS app)

Valkey.app is a free, open-source Mac app for running Valkey servers, like Postgres.app is for PostgreSQL. It needs no Homebrew, Docker or Terminal.

  1. Download Valkey.dmg and drag Valkey.app into Applications.
  2. Open it. The app isn't notarized yet, so allow it once: step-by-step instructions.
  3. Click Create Server…, pick a Valkey version, and click Start.

Each server gets its own port, version, data directory and live log. Use Connect… to open valkey-cli, or add modules such as JSON and Bloom in Server Settings.

Download Valkey.app

2. Homebrew

brew install valkey
brew services start valkey   # start now and at login

Stop it with brew services stop valkey. Homebrew installs one Valkey version at a time and upgrades it with brew upgrade valkey.

3. Docker

docker run -d --name valkey -p 6379:6379 valkey/valkey:latest

Replace latest with a version tag such as 8.1 to pin a version. The valkey/valkey-bundle image includes the official modules. Add -v valkey-data:/data to keep your data when the container is removed.

4. Build from source

xcode-select --install
curl -LO https://github.com/valkey-io/valkey/archive/refs/tags/9.1.2.tar.gz
tar xzf 9.1.2.tar.gz && cd valkey-9.1.2
make
./src/valkey-server

Building from source gives you full control, but you manage updates, configuration and startup yourself.

Check that Valkey is running

valkey-cli ping
# PONG

Valkey listens on port 6379 by default and speaks the Redis protocol, so redis-cli, Redis client libraries and GUI tools that support Redis connect to it too.
