## What's new

- **Command line: `valkey-app`.** Everything you can do in Valkey.app, you can now do from the terminal, and AI agents can too: create, start, stop and restart servers, change settings, add users, read logs and live stats, connect with `valkey-cli`, and install Valkey versions and modules. Every command has `--json` output for scripts and agents, plus help and examples (`valkey-app help`, `valkey-app help create`). It drives the running app, starting it in the background if needed, so the app and the command line always agree.
- **Install CLI.** **Settings → Command Line → Install CLI** adds `valkey-cli` and `valkey-app` to `/usr/local/bin`, so they work in any terminal. There's no line to copy into your shell profile. macOS asks for your password once. You can also run `valkey-app app install-cli`.
- **Tab completion** for zsh, bash and fish: commands, options, values, and your server and user names. **Install CLI** sets it up, or run `valkey-app completion zsh|bash|fish`.
- **Familiar shortcuts.** `valkey-app ls`, `rm`, `new`, `info`, `edit`, `log`, and `rm`/`ls`/`add` under `user`, `versions` and `modules` all work.

## Fixes

- **Saving settings in two places at once no longer loses changes.** Editing a server in the app and from the command line at the same time, or while a download is in progress, is now detected instead of overwriting the newer settings.
