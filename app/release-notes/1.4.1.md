## What's new

- **Send feedback or report a bug by email.** **Send Feedback…** and **Report a Bug…** are in the Help menu and the menu-bar menu. Each opens a draft email you can read and edit before sending. A bug report includes your app, macOS and Valkey versions and each server's state and recent log lines, but no file paths.
- **Report errors in one click.** Error messages (a server that won't start, a failed install or download) now have a **Report a Bug…** link that puts the error text into the email.
