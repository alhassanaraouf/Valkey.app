## What's new

- **Automatic updates.** Valkey.app now checks for updates. When one is available, it shows the release notes and asks before downloading. Once you confirm, it installs the update and relaunches, and servers that were running start again. Check any time with **Check for Updates…** in the app menu, the menu-bar menu or Settings, and turn automatic checks on or off in **Settings → Updates**.
- **⌘Q keeps Valkey running** in the menu bar while the menu-bar icon is shown, so your servers stay up. To really quit, use **Quit** in the menu-bar menu or the Dock icon's menu. With the menu-bar icon turned off, ⌘Q quits.
- **Ghostty without the prompt.** Connect… now opens `valkey-cli` through Ghostty's AppleScript support (Ghostty 1.3 or later), so Ghostty no longer asks "Allow?" every time. macOS asks once for permission to control Ghostty.
