## What's new

- **Modules.** Add official Valkey modules to any server: **JSON** (JSON documents with JSONPath queries) and **Bloom** (Bloom filters). Open **Server Settings → Modules → Add Module…**, search the catalog, and add what you need. Modules download when you save.
  - Each module build is tested against every Valkey version it's offered for, so you only see modules that work with your server's version.
  - A server with a module turned on won't start without it, because data saved with a module can't be loaded without that module. Removing a module from a server shows a warning.
  - **Versions…** lists installed module builds, with Install and Remove.

## Fixes

- **Logging out or restarting no longer gets blocked.** Quitting from the Dock, logout, restart and scripts now always quit Valkey.app and stop your servers gracefully. Before, with no Valkey window open, those quits could be cancelled. ⌘Q still closes Valkey to the menu bar while the menu-bar icon is shown.
