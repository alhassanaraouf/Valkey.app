## What's new

- **Password and users.** **Server Settings** has a password for the default user and a **Users** list for extra accounts, each with its own password and full or read-only access. Passwords are kept in your Keychain, not in the saved server list, and are handed to the server privately rather than on its command line.
- **Copy URL.** Copies `valkey://127.0.0.1:PORT` (with the password when one is set) from the server's window or its menu-bar menu. With extra users it offers one entry per user.
- **Max memory and eviction policy.** Set a memory limit and what the server does when it's full.
- **Save data to disk.** Turn it off for a cache-only server with no data files.
- **Live stats.** A running server's window shows memory, operations per second, clients, keys and hit rate, with graphs of the last few minutes.
- **Crash recovery.** A server that exits unexpectedly is restarted automatically and you get a notification. If it keeps failing (3 times in a minute) it's left stopped. Turn this off per server in **Server Settings**.
- **Log filter.** Type in the **Filter** box above a server's log to show only matching lines.
- **Edit valkey.conf.** The **Files** menu opens a server's config in your text editor. **Start** becomes **Restart** while the server runs, to apply changes.
- **valkey-cli on your PATH.** **Settings → Command Line** links `valkey-cli` to the newest installed version and shows the line to add to your shell profile.
